These are the third parties that process personal data for Uncava. Each is bound by a contract to protect the data and use it only to provide its service to us.

## Infrastructure

| Provider     | What it does for Uncava                                                                    | Location                      |
| ------------ | ------------------------------------------------------------------------------------------ | ----------------------------- |
| Google Cloud | Hosts the application, database, document storage and encryption keys                      | United States (`us-central1`) |
| Google Cloud | Vertex AI (Gemini): drafts briefs, proposes companies, assesses candidates, writes openers | United States (`us-central1`) |
| Firebase     | Hosts the uncava.com website                                                               | Global CDN                    |
| Cloudflare   | DNS for uncava.com                                                                         | Global                        |
| Resend       | Sends account email such as verifications, invitations and password resets                 | [Region]                      |

## Email, calendar and meetings

These act only when a user connects the matching account.

| Provider  | What it does for Uncava                                              | Location              |
| --------- | -------------------------------------------------------------------- | --------------------- |
| Nylas     | Connects mailboxes and calendars to send outreach and detect replies | United States [or EU] |
| Recall.ai | Optional calendar sync, when a workspace turns it on                 | [United States or EU] |
| Zoom      | Creates the Zoom meetings users book                                 | United States         |

## Company and executive data

These supply professional information about companies and executives, and receive the company names or profile addresses a search looks up.

| Provider    | What it does for Uncava                             | Location      |
| ----------- | --------------------------------------------------- | ------------- |
| Apollo      | Company database                                    | United States |
| Bright Data | Professional profile data                           | [Region]      |
| HarvestAPI  | Refreshes a public professional profile on request  | [Region]      |
| ContactOut  | People search and business email and phone look-ups | [Region]      |
| Mapbox      | Maps and place look-ups for the talent map          | United States |

## Changes to this list

We update this page before a new sub-processor starts processing customer data. Customers with a signed [Data processing addendum](/dpa) can ask to be notified by email at [Privacy email address] and may object as the addendum describes.
